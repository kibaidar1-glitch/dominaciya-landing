
# Project Instructions — ДОМИНАЦИЯ

## Project
Create a polished landing page for ДОМИНАЦИЯ,
an original ancient-philosophy-themed tabletop card game
with a Print & Play edition.

Read these files before making significant changes:
- PROJECT.md
- DESIGN.md
- CONTENT.md
- PLAN.md

## Workflow
- Inspect the existing repository before changing files.
- Work in small, reviewable iterations.
- Follow PLAN.md and update task status as work progresses.
- Do not rebuild unrelated parts of the project.
- Explain important decisions and report completed checks.

## Design
- Follow DESIGN.md as the source of truth.
- Preserve the game's established visual identity.
- Prefer distinctive art direction over generic landing page templates.
- Do not use generic AI-generated gradients, excessive glassmorphism,
  random decorative icons, or unnecessary animations.
- Use real game assets whenever available.
- Never invent official game components, logos, or card artwork.

## Content
- Follow CONTENT.md for all public-facing copy.
- Write in Russian unless explicitly requested otherwise.
- Do not invent game rules, player counts, prices, testimonials,
  awards, or download links.
- Clearly mark missing information instead of fabricating it.

## Implementation
- Use TypeScript and reusable React components.
- Follow the framework and package manager already in the repository.
- Make the page responsive and accessible.
- Use semantic HTML and meaningful alt text.
- Avoid unnecessary dependencies.
- Keep assets optimized and preserve image quality.

## Quality checks
- Run the available lint, type-check, and build commands.
- Check mobile and desktop layouts.
- Verify navigation, CTA buttons, and download links.
- Fix errors introduced by your changes.
- Report any checks that could not be completed.
