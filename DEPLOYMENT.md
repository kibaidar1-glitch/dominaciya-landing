# Подготовка к публикации

## Сборка

Требуется Node.js, совместимый с Vite 6, и pnpm.

```powershell
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm run build
```

Загрузите содержимое папки `dist/` в любой статический хостинг с раздачей файлов из корня сайта. Для локальной проверки production-сборки выполните `pnpm run preview`.

## Что нужно учесть перед публикацией

- Сборка включает `Dominacia-print-and-play.pdf` (около 166 МБ). Проверьте лимит размера загрузки и раздачи файлов у выбранного хостинга. Если лимит ниже, разместите PDF в объектном хранилище/CDN и замените `downloadPath` в `src/data.ts` на постоянный публичный URL.
- Проект использует корневые URL (`/optimized/...` и `/Dominacia-print-and-play.pdf`), поэтому публикуйте его в корне домена. Для размещения в подпапке потребуется настроить `base` в `vite.config.ts` и проверить ссылки.
- Перед запуском на домене замените относительный `og:image` в `index.html` на абсолютный URL изображения для социальных превью.
- Команда lint в проекте не настроена. `pnpm run build` выполняет проверку TypeScript перед созданием production-сборки.

## Файлы и изображения

Публичные изображения страницы находятся в `public/optimized/` в формате WebP. Исходные PNG сохранены в `source-assets/` и не копируются в `dist/`. PDF остается в `public/`, чтобы ссылка на скачивание работала в локальном preview и production-сборке.
