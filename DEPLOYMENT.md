# Подготовка к публикации

## Сборка

Требуется Node.js, совместимый с Vite 6, и pnpm.

```powershell
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm run build
```

Загрузите содержимое папки `dist/` в любой статический хостинг с раздачей файлов из корня сайта. Для локальной проверки production-сборки выполните `pnpm run preview`.

## Что нужно учесть перед публикацией

- PDF размещен в официальном релизе игры на GitHub (версия 1.0.0); сайт ссылается на него напрямую, поэтому большой файл не включается в сборку Netlify. При выпуске новой версии обновите ссылку `downloadPath` в `src/data.ts`.
- Проект использует корневые URL (`/optimized/...` и `/Dominacia-print-and-play.pdf`), поэтому публикуйте его в корне домена. Для размещения в подпапке потребуется настроить `base` в `vite.config.ts` и проверить ссылки.
- Канонический адрес и абсолютный `og:image` настроены на `https://dominacia.netlify.app/` в `index.html`.
- Команда lint в проекте не настроена. `pnpm run build` выполняет проверку TypeScript перед созданием production-сборки.

## Файлы и изображения

Публичные изображения страницы находятся в `public/optimized/` в формате WebP. Исходные PNG сохранены в `source-assets/` и не копируются в `dist/`. Игровой PDF загружается из официального релиза игры на GitHub.
